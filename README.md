# sit

RAS — *Reserve A Seat*: a site around Nigeria's 2027 elections.

- `web/` — Astro + three.js site (`cd web && npm install && npm run dev`)
- `blender/` — Python scripts that build the Blender scenes (`build_ras_scene.py`, `build_crowd.py`)
- `docs/` — notes and pipeline docs

Heavy files (`.blend` scenes, renders, `Assets/` video/audio) are **not** in git — they sync via the cloud folder.
